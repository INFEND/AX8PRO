# AX8 PRO CONTROL v1.5.4 (22)

## Исправления
- Мониторинг: текущий интервал режима «Автоматически» расположен справа от выбора режима. Ручной ползунок 0,5–5 секунд остаётся видимым.
- При старте из локального сохранённого снимка показываются последние доступные данные, а новый LTE-статус отображается сразу после ответа роутера, не дожидаясь SMS/ACL.
- Отображается значок молнии рядом с процентами батареи при подтверждённой зарядке.
- Экран обновления использует единое тематическое окно, короткую кнопку обновления и анимированный индикатор загрузки.
- Добавлена автоматическая проверка обновления при запуске (когда функция включена).
- Название в лаунчере: AX8 PRO CONTROL.
- Подключён ACTION_INSTALL_PACKAGE и обработчик MY_PACKAGE_REPLACED с действием открытия приложения из уведомления после обновления.
- OTA-клиент поддерживает оба адреса релизов после переименования аккаунта. Для старых установок сохранён совместимый формат APK-ссылки.
- Тексты окна обновления больше не упоминают платформу публикации.

## Проверки и ограничения
- Изменения сохранены в ветке main.
- После успешной GitHub Actions сборки приложение получит обновление версии 1.5.4 (22) через OTA.
- Точное поведение системной кнопки «Открыть» контролирует установщик Android; при наличии разрешения на уведомления приложение предоставляет альтернативное действие.
- Полную компиляцию APK и работу на устройстве следует подтверждать результатом релизного workflow и испытанием на телефоне.

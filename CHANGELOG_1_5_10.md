# AX8 PRO CONTROL 1.5.10 (28)

## Исправления

- **SMS / фон:** при сворачивании приложения список SMS, видимый в интерфейсе, теперь объединяется с уже сохранённой историей идентификаторов вместо её перезаписи. Ранее открытие приложения с частично загруженной страницей SMS могло стереть часть истории и вызвать повторные уведомления о старых сообщениях.
- **SMS / память:** сохранён лимит истории 1000 идентификаторов и фильтрация некорректных ID через общий SmsAlertPlanner.
- **Тесты:** добавлены три регрессионных сценария перехода интерфейс → фоновый мониторинг (всего 19).

## Совместимость

- applicationId, постоянный ключ подписи и формат OTA не изменены.
- Реальная работа с OLAX AX8 Pro и Android 17 требует испытаний на устройстве.

# AX8 PRO CONTROL 1.5.5 (23)

## Исправления
- Устранён NullPointerException в фоновом мониторинге, когда запрос списка Wi-Fi-клиентов завершился ошибкой, но статусное уведомление пыталось вызвать `devices.size()`. Теперь вместо ложного количества выводится «?», а ошибки опроса сохраняются отдельно.
- Убрана повторная регистрация второго обработчика `MY_PACKAGE_REPLACED`. После обновления не должно приходить два уведомления «Открыть приложение» от разных обработчиков.
- Добавлены три автономных Java-регрессионных теста на неизвестное, нулевое и положительное число клиентов; включены в GitHub Actions.

## Проверки и ограничения
- Локально выполнены тесты `BackgroundSummaryTest` (3/3).
- Android-сборка, подпись, OTA-манифест и публикация проверяются GitHub Actions после коммита.
- Испытания на реальном OLAX AX8 Pro не выполнялись. Поведение уведомлений зависит от разрешений Android и настроек каналов.

# AX8 PRO CONTROL 1.5.8 (26)

## Исправления

- **SMS:** неполный ответ роутера без массива `messages` больше не считается пустым списком сообщений. Сохранённая история уже обнаруженных SMS не стирается при таком сбое, поэтому старые сообщения не должны повторно объявляться новыми после восстановления соединения.
- **SMS:** поддерживается массив сообщений, переданный роутером в виде корректной JSON-строки. Некорректная строка приводит к диагностируемой ошибке, а не к ложному нулю сообщений.
- **Фоновый режим:** после завершения ожидающего фонового задания повторно освобождаются CPU/Wi-Fi WakeLock. Это устраняет риск удержания блокировок после остановки службы во время активного опроса.

## Проверка

- Android Gradle и Java-тесты выполняются в GitHub Actions перед публикацией.
- Фактическая работа на реальном OLAX AX8 Pro и Android 17 требует проверки на устройстве.
- Подпись и схема OTA остаются без изменений.

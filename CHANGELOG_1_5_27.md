# AX8 PRO CONTROL v1.5.27 (45)

## Зарядка батареи
- Исправлено получение признака зарядки: один общий запрос к LTE-статусу недостаточно надёжен для всех прошивок.
- Добавлен независимый короткий запрос полей зарядки раз в пять секунд, без изменения настроек AX8.
- Дополнительно проверяется отдельный запрос `battery_charging`; подтверждённый ответ используется для молнии.
- Значение 100% не считается признаком зарядки, а отсутствие поля не подменяется ложным состоянием.
- При переподключении к роутеру старый кэш состояния зарядки сбрасывается.
- Новая кнопка «Персонализация → Проверить состояние зарядки» показывает реальные ответы общего и отдельного запросов, отдельно выделяя «Заряжается», «Не заряжается» и «Нет данных».
- Силуэт батареи по-прежнему можно скрыть независимо от настоящей молнии зарядки.

## Проверка
- Расширены тесты обработки отсутствующего, положительного и отрицательного ответа `battery_charging`.
- Публикация подписанного APK и работоспособность конкретной прошивки AX8 требуют подтверждения успешного GitHub Actions и проверки на устройстве.
